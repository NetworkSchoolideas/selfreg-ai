## 🚀 Быстрый старт: Настройка API ключей

## 📋 Что реализовано

Каждый пользователь может подключить **СВОЙ ЛИЧНЫЙ API ключ** для любого провайдера ИИ. Ключи хранятся **локально в браузере** и никогда не отправляются на сервер.

**Поддерживаемые провайдеры:**
- ✅ **OpenRouter** - 100+ моделей, простой API key
- ✅ **GitHub Models** - бесплатно для GitHub пользователей
- ✅ **GigaChat (Direct)** - прямой доступ с вашим личным ключом
- ✅ **Vercel AI Gateway** - для Vercel инфраструктуры
- ✅ **Mock** - без ключей (тестирование)

---

## ⭐ Рекомендованная настройка: OpenRouter

**Почему OpenRouter:**
- ✅ Простой API key (как у всех остальных)
- ✅ Доступны 100+ моделей (OpenAI, Anthropic, Google и др.)
- ✅ Работает из любой страны
- ✅ Единый ключ для всех моделей
- ✅ Бесплатный тариф доступен

**Как настроить:**

```
1. Откройте https://openrouter.ai/
2. Зарегистрируйтесь
3. Создайте API key (Keys → Create Key)
4. В приложении:
   - Провайдер: OpenRouter
   - Модель: openrouter/free (или конкретная модель)
   - API Key: вставьте OpenRouter ключ
5. Готово!
```

## 🎯 GigaChat через ваш личный ключ

**Важно:** GigaChat использует OAuth 2.0, поэтому:
- Вы вводите постоянный **Authorization Key** (Client ID + Client Secret)
- Система получает временный **Access Token** (30 минут)
- Токен кэшируется на 25 минут
- Всё работает автоматически

**Как настроить:**

```
1. Получите Client ID и Client Secret:
   - https://developers.sber.ru/
   - GigaChat → Мои приложения → Создать приложение
   - Скопируйте Client ID и Client Secret

2. Сгенерируйте Authorization Key (base64):
   PowerShell: [Convert]::ToBase64String([Text.Encoding]::ASCII.GetBytes("CLIENT_ID:CLIENT_SECRET"))

3. В приложении:
   - Провайдер: GigaChat (Direct)
   - API Key Settings → вставьте Authorization Key
   - Нажмите "Проверить" (рекомендуется)
   - Сохраните
```

**Готово!** Система автоматически:
- Получает Access Token
- Кэширует его на 25 минут
- Использует для запросов
- Обновляет при истечении

## 📖 Инструкция для каждого провайдера

---

### **1. OpenRouter (Рекомендуется)**

**Зачем:** Основной провайдер, 100+ моделей

**Как получить ключ:**

1. Зайдите на https://openrouter.ai/
2. Зарегистрируйтесь (через GitHub/Google/Email)
3. Перейдите: **Keys** → **Create Key**
4. Название: `SelfReg AI`
5. Скопируйте ключ (начинается с `sk-or-v1-...`)

**Вставьте в API Key Settings**

**Доступные модели:**
- `openai/gpt-4o-mini` - OpenAI
- `anthropic/claude-3-haiku` - Anthropic
- `google/gemini-pro` - Google
- И 100+ других...

---

### **2. GigaChat (Direct - ваш личный ключ)**

**Зачем:** Прямой доступ к GigaChat с вашим ключом

**Как получить Client ID и Client Secret:**

1. Зайдите на https://developers.sber.ru/
2. Войдите через Госуслуги/Sber ID
3. Перейдите: **GigaChat** → **Мои приложения**
4. Нажмите **Создать приложение**
5. Заполните:
   - Название: `SelfReg AI`
   - Описание: `Прототип для подростков`
   - Callback: `http://localhost:3000`
6. Скопируйте **Client ID** и **Client Secret**

**Сформируйте Authorization Key:**

```powershell
# Windows PowerShell:
[Convert]::ToBase64String([Text.Encoding]::ASCII.GetBytes("CLIENT_ID:CLIENT_SECRET"))

# Или онлайн: https://www.base64encode.org/
```

**Пример:**
```
Client ID: abc123-xyz
Client Secret: def456-uvw
→ Склеиваем: abc123-xyz:def456-uvw
→ base64: YWJjMTIzLXh5ejpkZWY0NTYtdXZ3
```

**В приложении:**

1. Выберите провайдер: `GigaChat (Direct)`
2. Нажмите **🔑 API Key Settings**
3. Вставьте Authorization Key (результат base64)
4. Нажмите **Проверить** (рекомендуется)
5. Нажмите **Сохранить**

**Как это работает:**
```
Ваш браузер:
  ├─ Authorization Key сохраняется в localStorage
  ├─ При запросе автоматически:
  │   1. Получает Access Token (через /oauth)
  │   2. Кэширует на 25 минут
  │   3. Использует для запросов
  └─ Обновляет токен при истечении

Сервер:
  └─ НЕ видит ваш ключ (только браузер → GigaChat)
```

### **3. GitHub Models**

**Как получить токен:**

**Вставьте в API Key Settings**

**Модель:** `openai/gpt-4o-mini` (бесплатно, 1M токенов/месяц)

## 🔒 Безопасность

### Где хранятся ключи?

```
✅ Ваш браузер (localStorage)
   └─ Только вы видите ключ
   └─ Никогда не отправляется на наш сервер
   └─ Сохраняется между сессиями

❌ Наш сервер
   └─ Мы НЕ храним ваши ключи
   └─ Мы НЕ видим ваши ключи
   └─ Мы НЕ имеем доступа к вашим ключам
```

### Как используются ключи?

```
Ваш браузер
   ├─ Вводите ключ → сохраняется в localStorage
   ├─ Запрос на /api/chat с ключом
   └─ Ключ передаётся провайдеру (GigaChat/OpenRouter)

Наш сервер (/api/chat)
   ├─ Получает ключ в запросе
   └─ Пересылает провайдеру (только для передачи)

Провайдер (GigaChat/OpenRouter)
   └─ Обрабатывает запрос с вашим ключом
   └─ Возвращает ответ
```

## 🐛 Частые проблемы

### "Invalid API key"

**Причина:** Ключ неверный или просрочен

**Решение:**
1. Проверьте, что нет пробелов
2. Зайдите в панель провайдера и проверьте статус ключа
3. Сгенерируйте новый ключ
4. Удалите старый и вставьте новый

---

### "403 Forbidden"

**Причина:** Ограничения по региону или недостаточно средств

**Решение:**
- GigaChat: Требует регион РФ (может понадобиться VPN)
- OpenRouter: Проверьте баланс
- GitHub: Проверьте права токена

---

### Ключ не сохраняется

**Причина:** localStorage отключен или очищен

**Решение:**
1. Проверьте настройки браузера → Разрешить localStorage
2. Очистите кэш и введите ключ заново
3. Попробуйте режим инкогнито
