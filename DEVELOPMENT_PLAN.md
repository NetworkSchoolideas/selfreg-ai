### ?? Известные проблемы

#### Критическая: Нет разделения ролей при регистрации
**Проблема:** При регистрации пользователя не спрашивают, кто он - учитель или ученик.

**Текущая логика:**
- `AdolescentPrototype.tsx` - только для учеников
- Нет формы регистрации для учителей
- Нет поля `role` в форме регистрации
- В `profiles` таблице есть поле `role`, но оно не заполняется

**Что происходит:**
1. Пользователь регистрируется через AdolescentPrototype
2. Создаётся запись в `profiles` с `role = null` или по умолчанию
3. При попытке зайти на `/teacher` middleware проверяет `role === 'teacher'`
4. Доступ закрыт, даже если пользователь хочет быть учителем

#### Вторичная: Нет учителя дашборда
- Маршрут `/teacher` существует, но нет UI для учителя
- Нет страницы с аналитикой по ученикам

## Технические детали

### База данных (Supabase)

**Таблица `profiles`:**
```sql
id (UUID, PK)
email (text)
role (text) -- 'teacher', 'student', null
teacher_id (UUID, FK to profiles) -- для учеников
created_at (timestamp)
```

**Таблица `children`:**
```sql
id (text, PK) -- anonId
name (text)
className (text)
teacherId (text) -- ссылка на учителя
consentGiven (boolean)
consentTimestamp (timestamp)
sessions (jsonb)
```

### Маршруты

| Маршрут | Доступ | Описание |
|---------|--------|----------|
| `/` | Public | Главная страница |
| `/role-selection` | Public | Выбор роли (новый) |
| `/teacher/register` | Public | Регистрация учителя (новый) |
| `/teacher/dashboard` | Auth + teacher | Дашборд учителя (новый) |
| `/adolescent` | Public | Сессия ученика |
| `/settings` | Auth | Настройки профиля |
